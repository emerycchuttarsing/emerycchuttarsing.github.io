## Tentatives d'observation REA dans Chrome

Deux profils Chrome temporaires, sans compte personnel, ont été ouverts pour les seuls sites étudiés, avec points CDP locaux 127.0.0.1:9337 et :9338. Chrome annoncé : 155.0.8059.79.

`list-browser-targets` a réussi pour les deux sites. `inspect-web-page` avec scripts et texte d'accessibilité n'a pas produit de capture complète avant le délai de 90 secondes. Les processus Chrome temporaires ont été arrêtés pour réduire la charge. Ne pas présenter cette tentative comme une analyse runtime réussie, ni interpréter un journal réseau vide comme l'absence de requêtes.

## Analyse statique

Le HTML et les scripts publiés ont été téléchargés comme données. Les ressources d'Ing Tian ont pu être suivies ; les modules principaux de Mirage ont répondu HTTP 403 au téléchargement direct. Les données et le script d'amorçage présents dans son HTML restaient lisibles.

L'analyse statique initiale d'Ing Tian a échoué parce que la compilation de l'utilitaire macOS de REA tentait d'écrire son cache hors du bac à sable. Une relance autorisée hors du bac à sable, avec caches de compilation sous `/private/tmp`, a abouti. Aucun script de site n'a été exécuté par l'analyse statique.

Les premiers rapports larges étaient partiels et comprenaient des scripts intégrés extraits de façon redondante, dont du JSON-LD improprement enregistré en `.js`. Ils ne sont pas utilisés comme référence principale. Deux analyses ciblées sur des scripts JavaScript effectifs ont ensuite abouti avec 0 erreur de parsing :

## Complément : accès et analyse des modules 3D Mirage

Le même soir, 18 modules JavaScript, le modèle GLB et le manifeste des couleurs
ont été téléchargés avec succès (20 ressources, 1 234 750 octets, 0 échec).
Les requêtes utilisaient un User-Agent et un Referer explicites. La cause exacte
des 403 précédents n'a pas été isolée. Ces téléchargements rendent caduque la
limitation d'accès aux modules notée dans le premier pilote.

REA 6.4.0 a analysé le répertoire des 18 scripts : 1 187 388 octets,
308 222 nœuds AST, 777 constats, 0 erreur de parsing. Le graphe applicatif
comporte 169 nœuds et 816 relations. La couverture reste partielle : les gros
modules ont atteint certains budgets sémantiques de mémoire et de sortie.
Cela n'a pas empêché la lecture manuelle des mécanismes ni la résolution des
imports utiles. Aucun JavaScript téléchargé n'a été exécuté par cette analyse.
